### Hi, I'm Iladin

DevOps engineer and Java developer. I build the platforms and pipelines other teams ship on (Kubernetes, GitLab CI/CD, Kafka), and I move legacy COBOL/DB2 systems onto Linux and PostgreSQL without breaking them.

- **Platform:** Kubernetes · Docker · Terraform · Ansible · Vagrant
- **CI/CD:** GitLab CI · GitHub Actions · SonarQube
- **Data in motion:** Kafka · Kafka Connect · Debezium CDC · PostgreSQL · DB2 · SQL Server
- **Backend:** Java (Quarkus, Maven, Gradle) · Go · Bash · C
- **Observability:** Prometheus · Grafana · OpenTelemetry
- **Legacy:** COBOL (GnuCOBOL, gcobol) · embedded SQL · DB2 → PostgreSQL migration
